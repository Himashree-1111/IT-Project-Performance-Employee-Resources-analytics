IT Project Performance and Employee Resource Analytics

Project Overview

This project analyzes IT project performance and employee resource utilization to support data-driven business decisions. It focuses on project budgets, revenue, employee performance, working hours, and IT ticket management.

Objectives

- Analyze employee distribution across departments and roles.
- Compare project budgets and revenue.
- Evaluate planned hours against actual hours.
- Examine project status and employee performance.
- Analyze IT tickets by priority.
- Explore salary differences across departments.
- Track client satisfaction trends.

Tools and Technologies

- Python: Data analysis and data cleaning
- Pandas and NumPy: Data manipulation
- SQL: Data querying and analysis
- Excel: Data preparation and reporting
- Power BI: Dashboard development and visualization

Key Performance Indicators (KPIs)

- Total Employees
- Total Projects
- Total Revenue
- Total Budget
- Total IT Tickets
- Average Employee Performance

Dashboard Analysis

The project dashboard is designed to explore:

- Employee distribution by department
- Project budget versus revenue
- Planned hours versus actual hours
- Project status distribution
- Hours by employee role
- Average salary by department
- IT tickets by priority
- Monthly client satisfaction trends

Data Analysis Process

1. Prepare and inspect the dataset.
2. Check data quality, missing values, duplicates, and data types.
3. Clean and transform data where required.
4. Perform SQL queries and Python-based analysis.
5. Develop visualizations and dashboard KPIs.
6. Interpret verified results and identify actionable business recommendations.

Business Value

The analysis can help organizations monitor project performance, understand resource utilization, track operational metrics, and support workforce planning.

Repository Contents

This repository contains project analysis files and dashboard materials. Refer to the folders and files in this repository for the available SQL, Python, and dashboard components.

Key Insights

Based on the IT Project Performance and Employee Resource Analytics dashboard, the following results were observed:

- Workforce: The dashboard reports 250 employees across five departments, with IT having the largest workforce at 80 employees.
- Project Portfolio: The dashboard reports 250 total projects. The displayed project status distribution is 40% completed, 25% in progress, 20% on hold, and 15% cancelled.
- Revenue and Budget: Total revenue is reported as ₹2.015 billion, compared with a total budget of ₹1.336 billion.
- Department-wise Salary: IT has the highest displayed average salary at ₹85,000, while HR has the lowest at ₹45,000.
- IT Support: The dashboard reports 500 IT tickets, with medium-priority tickets accounting for the largest category at 180.
- Resource Utilization: Planned hours total 6,200, compared with 5,480 actual hours, a difference of 720 hours.
- Client Satisfaction: Monthly satisfaction scores range from 3.8 to 4.6 out of 5, reaching their highest displayed value in November.

These dashboard metrics provide a consolidated view of project status, financial performance, workforce distribution, support-ticket priorities, working hours, and client satisfaction.
